[B]AB Scrapers v1.1.2[/B]
- CocoScrapers engine updated 1.0.43 -> 1.0.44.
- Episode air-date matching (upstream 1.0.44): when the calling add-on sends the episode's
  air date ("premiered"), every Coco TV provider also accepts releases named by date
  (Show.2026.10.22 / Show 2026-10-22) next to the usual SxxEyy. Text-search providers
  (1337x, BitSearch, Kickass, Knaben, LimeTorrents, Nyaa, PirateBay, Prowlarr, Rutor,
  Torlock, TorrentDownload, TorrentGalaxy, TorrentProject, Torrentz2) run a second,
  date-based query and the two result sets are merged by hash. Daily and talk shows
  (news, late-night, wrestling) now find sources. No air date -> behaviour unchanged.
- Same air-date support added to AB's extra Coco providers (BitCQ, Bitlord, isoHunt,
  TorrentFunk, TorrentQuest, YourBittorrent).
- Picked up 1.0.43 provider changes that 1.1.1 still lacked:
  - EZTV: paginated IMDb JSON API (numbered, air-date and season-pack matching) instead
    of website scraping; Auto now runs Gears (site search) + Coco (API) and merges;
  - Rutor: single-episode TV searches; Auto now uses the Coco engine for Rutor
    (same site as Gears, which only searches movies);
  - Knaben: query building cleanup.
- FIX AIOStreams player returned "No Results" instantly, with nothing in kodi.log, when
  AIOStreams Player > Username/Password were empty (the scraper login under Instances was
  not used). Now: player login -> else the scraper login and instance -> else an anonymous
  search with the built-in config (same as the AIOStreams scraper).
  Every search now logs which login/instance was used, HTTP 401/403 (wrong UUID for that
  instance) and 0-result searches.
- AIOStreams player without a login: the built-in config has no debrid, so AIOStreams
  returns only P2P torrents, which the player drops (it plays debrid links only) - it
  found 1313 results and showed none. The debrid keys authorized in Account Manager
  (Real-Debrid, AllDebrid, Premiumize, TorBox, OffCloud, EasyDebrid) are now added to the
  built-in config, so AIOStreams returns playable debrid links.
  If only P2P comes back, the count is logged and a notification says what to set.

[B]AB Scrapers v1.1.1[/B]
- NEW "Check provider access (blocked / banned)" - Maintenance, and the add-on's main menu.
  Probes every host each provider uses (with the engines that actually run for it) and tells why
  one is unreachable, instead of the health check's bare "0 results":
  - Blocked (DNS): your DNS gives no / a sinkhole address while public DNS (DNS-over-HTTPS) resolves it;
  - Blocked (connection cut): DNS fine, connection reset during connect/TLS (ISP SNI filter);
  - Blocked (block page): ISP / regulator "site blocked" page (English and Arabic markers);
  - Banned (HTTP 403), Rate-limited (429), Blocked (legal, 451), Cloudflare challenge,
    No response (timeout), Site error (5xx), Domain dead.
  A provider counts as reachable if any of its mirrors answers. Selecting a provider shows each
  host, its IP, HTTP code, details and the matching fix (DNS change vs VPN vs wait).
- Every result is also written to kodi.log as "[Access] provider: STATUS | host=STATUS (...)".
- Arabic description now says 54 providers.

[B]AB Scrapers v1.0.3[/B]
- NEW Filters > "Filter repeated results" (default: Same release name and size):
  indexers such as Comet return the same release several times under different
  info-hashes (identical name, identical size); the add-on only removes identical
  hashes, so every copy was listed. Modes: Off / Same hash / Same release name and size.
  The copy with the most seeders is kept.
- "Also across providers in the same search" (default on): a release already returned
  by one provider is not listed again from another.
- kodi.log shows "<provider>: N repeated results filtered (M kept)".

[B]AB Scrapers v1.0.0[/B]
- First release. One module built from three engines:
  - CocoScrapers 1.0.39
  - Gears Scrapers 1.6.2
  - Magneto 6.10.04
- 51 providers in total (27 exist in one engine, 24 in two or three).
- Multi-engine providers: when a provider exists in several engines with different
  instances, mirrors or APIs (Comet, MediaFusion, TorrentGalaxy, Knaben, Torlock,
  Torz, Zilean, YTS, LimeTorrents, TorrentProject), AB Scrapers runs them in parallel
  and merges the results by info-hash, keeping the copy with the most seeders.
- Per-provider engine selector: Auto (curated) / All engines / one engine.
- One shared settings store for every engine (picks up on-disk changes without restart).
- Magneto instance selectors for Comet, Torz and Zilean.
- CocoScrapers MediaFusion custom URL + device setup; fixed the upstream mismatch
  between the saved user-data setting and the setting the provider read.
- CocoScrapers Prowlarr test/indexer buttons now use the same URL/API key as the providers.
- Gears Telegram (TorrentSearchRoBot) provider with per-device account linking.
- Magneto AIOStreams player + TMDbHelper player JSON.
- Unified health check showing which engines answered for each provider.
- English and Arabic (Modern Standard) interface strings.
