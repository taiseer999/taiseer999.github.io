
طريقة تفويض TorBox:

1. اختر «تفويض»
2. أدخل مفتاح API الخاص بك
3. تأكد من صحة البيانات المُدخلة
4. اختر «موافق» لمزامنة بياناتك مع الإضافات المدعومة

طريقة تفويض OffCloud:

1. اختر «تفويض»
2. أدخل بيانات تسجيل الدخول
3. تأكد من صحة البيانات المُدخلة
4. اختر «موافق» لمزامنة بياناتك مع الإضافات المدعومة
