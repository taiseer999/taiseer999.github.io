v3.2.4
- FIX (video 2026-10-03 09:49, AF3 power tray: empty slot, Force Close red in
  the editor): menu_reconcile asked System.HasAddon() whether
  plugin.program.ABUKARIMwizard is installed. Kodi lowercases condition
  strings, so a mixed-case id never matches (same root cause as
  wizard_runner 3.1.3) and the item was hidden. Mixed-case ids are now checked
  through JSON-RPC Addons.GetAddonDetails (installed + enabled); items hidden
  by mistake come back on the next boot or with Repair Menus & Widgets.
- Skin conditions are never generated for mixed-case ids (they could only
  ever evaluate false); bootstrap uses the same presence check.

v3.2.3
- FIX (log 2026-10-03 09:40, AF3 power tray "Skin Variables error", 0 items,
  could not edit): menu_reconcile tagged the items it hid with
  "abk_hidden": [ids] - a LIST. skinvariables passes every item field to
  ListItem.setProperties(), which only takes strings, so any node holding a
  hidden item raised TypeError and the whole menu failed. The tag is now a
  comma-separated string; list tags written by 3.2.0-3.2.2 are converted on the
  next boot (or Maintenance > Repair Menus & Widgets) and the skin's
  templates are rebuilt.

v3.2.2
- FIX (screenshot 2026-10-03 09:32): Remote Access showed "http://Busy:8080"
  - Network.IPAddress read from Python returned Kodi's "Busy" placeholder.
  The LAN address now comes from the OS (UDP socket, nothing is sent), with
  the info label as a retried fallback; never shows a non-IP value.

v3.2.1
- FIX (log 2026-10-03 09:07): the Remote Access / Share Log QR screen drew its

v3.2.0
- NEW Remote config: patches.json / portal.json / presets.json / config.json
  are read from taiseer999Piers.github.io/abukarim/ (refreshed at boot, max
  every 6 h, cache-only everywhere else). Patches can now be added or killed
  without a tools release; remote entries support min_version/max_version and
  target_sha256 so they never touch an upstream file they were not written for.
- NEW skins.json fields (all optional, old catalogs keep working):
  sha256 (download verified), companions (replaces the hardcoded map),
  min_kodi / max_kodi / platforms (incompatible skins are hidden),
  profile + profile_sha256 (Piers settings/menus/widgets per skin, applied
  before the skin is activated, previous files backed up).
- NEW Skin Profiles menu: export the current skin's profile as a portable zip
  (dev paths rewritten to special://home) + restore a profile backup.
- NEW Menu reconcile: menu items / widgets that point at an add-on that is not
  installed are hidden (skinvariables: disabled flag, skinshortcuts v3:
  System.HasAddon visible) and come back automatically once it is installed.
  Runs at boot and after the Add-on Portal; also in Maintenance.
- NEW First run: setup preset (Full / Lite / Plex-Emby / Custom) pre-ticks the
  Add-on Portal; device tuning sizes the video cache from RAM; every box gets
  its own web server password (shown once with a QR for Kore/Yatse); thin-build
  bootstrap installs add-ons listed in bootstrap.json from their repos.
- Tools menu entries for these are actions (not folders), per the 3.1.19 rule.
- segno (QR) vendored in resources/lib/vendor (OpenWizard copy was removed).
- NEW Share Log (QR): uploads kodi.log / kodi.old.log to paste.kodi.tv with
  keys, tokens, passwords, e-mails, debrid links and public IPs scrubbed.
- NEW Setup > Optimize for This Device, Remote Access, Finish Build Install;
  Patches > Update Online Fixes & Catalogs; Maintenance > Repair Menus.
