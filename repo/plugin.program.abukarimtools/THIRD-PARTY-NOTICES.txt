2. Ports from Lucent by djdirty60 (GPL-2.0-or-later)
----------------------------------------------------
https://github.com/djdirty60/Lucent - distributed here under GPL-3.0-or-later,
as GPL-2.0-or-later allows (resources/licenses/GPL-3.0.txt):

    resources/lucent_player/ (Includes_ABK_LucentPlayer.xml,
        ABK_LucentPlayerInfo.xml, media/) - see its README.txt
    tools/lucent_player/ (the scripts that make those files from Lucent)

These are skin files that the patcher installs into Arctic Fuse 3. The
Python that runs the Lucent Player features (resources/lib/lucent_playerinfo.py,
lucent_back.py) was written for AB Tools from scratch in 4.12.0 and is
AB Tools' own code; it only fills the window's properties. The AB Tools
designs that follow Lucent's look (resources/af3_lucent/, the settings window,
sub_list.py, streaming_rows.py) are AB Tools' own code and artwork.

5. Patches for other add-ons (resources/lib/patcher.py, resources/*/)
----------------------------------------------------------------------
The patcher changes add-ons installed on the device. Where a patch entry
(or a file under resources/ that replaces one) repeats lines of the add-on
it changes, those lines belong to that add-on and stay under its licence:

    TMDb Helper (plugin.video.themoviedb.helper) by jurialmunkey - GPL-3.0
    Seren (plugin.video.seren) - GPL-3.0
    Fen Light, Red Light, POV, Umbrella - the licence in each add-on
    TinyPPI (script.tinyppi) - the licence in the add-on
    Arctic Fuse 3 - see section 4

AB Tools does not ship these add-ons; it changes the user's own copies.
